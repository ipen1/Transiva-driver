Kebijakan Privasi Transiva Driver

Terakhir diperbarui: 1 September 2026

Transiva Driver adalah aplikasi operasional untuk mitra driver Transiva. Kebijakan ini menjelaskan data yang dapat diproses ketika driver menggunakan akun, menerima dan menyelesaikan pesanan, memakai navigasi, chat/panggilan, serta fitur pendapatan dan keamanan aplikasi.

Data yang diproses

Data dapat mencakup informasi akun seperti nama, nomor telepon, email dan ID driver; data pesanan dan perjalanan; informasi transaksi, saldo, deposit, penarikan atau transfer jika fitur tersebut digunakan; pesan dalam aplikasi; foto atau file yang dipilih pengguna; audio ketika pengguna memakai voice note atau panggilan; serta data teknis seperti token notifikasi, versi aplikasi, log crash dan diagnostik.

Lokasi dan lokasi latar belakang

Transiva Driver dapat mengumpulkan lokasi presisi ketika driver secara sengaja memilih ONLINE atau memiliki perjalanan aktif, termasuk di latar belakang ketika aplikasi ditutup atau tidak sedang digunakan. Lokasi digunakan untuk menentukan posisi operasional driver, pencocokan order di sekitar, menampilkan progres/posisi perjalanan kepada customer, dan membantu navigasi. Lokasi tidak digunakan untuk iklan. Layanan lokasi operasional dihentikan ketika driver OFFLINE dan tidak memiliki perjalanan aktif.

Kamera, foto, file, mikrofon dan panggilan

Kamera hanya digunakan ketika driver memilih fitur kamera. File/foto dapat dipilih melalui pemilih dokumen Android. Mikrofon digunakan ketika driver secara sengaja merekam voice note atau menggunakan fitur panggilan suara WebRTC. Transiva tidak mengaktifkan kamera atau mikrofon secara tersembunyi untuk tujuan iklan.

Notifikasi dan panggilan masuk

Transiva menggunakan notifikasi untuk order, chat, keamanan dan panggilan. Full-screen intent, bila tersedia dan diizinkan oleh Android, digunakan hanya untuk panggilan WebRTC masuk yang membutuhkan perhatian segera. Jika akses tersebut tidak tersedia, aplikasi menggunakan notifikasi panggilan dengan aksi Terima/Tolak.

Diagnostik dan analitik

Aplikasi menggunakan layanan Firebase seperti Cloud Messaging untuk notifikasi, Crashlytics untuk kestabilan/diagnostik, dan Analytics apabila pengumpulan Analytics diaktifkan pada build produksi. Data tersebut digunakan untuk menjalankan, mengamankan dan meningkatkan aplikasi.

Keamanan dan pengiriman data

Aplikasi produksi menggunakan koneksi HTTPS/TLS untuk komunikasi server dan menonaktifkan cleartext traffic Android. Transiva menerapkan kontrol akses pada layanan server dan membatasi data sesuai kebutuhan operasional.

Penyimpanan dan penghapusan

Data disimpan selama diperlukan untuk menyediakan layanan, memenuhi kewajiban transaksi/keamanan, menangani sengketa, dan memenuhi kewajiban hukum yang berlaku. Permintaan terkait akses, koreksi atau penghapusan data driver dapat disampaikan melalui kanal dukungan resmi Transiva. Sebagian data transaksi atau keamanan dapat dipertahankan jika diwajibkan oleh hukum atau diperlukan untuk pencegahan penyalahgunaan.

Berbagi data

Data dapat diproses oleh penyedia layanan yang membantu menjalankan aplikasi dan infrastrukturnya, misalnya layanan cloud/notifikasi/diagnostik, sejauh diperlukan untuk fungsi tersebut. Transiva tidak menjual data lokasi driver untuk periklanan.

Pilihan dan izin pengguna

Driver dapat menolak izin tertentu, tetapi fitur yang bergantung pada izin tersebut mungkin tidak dapat digunakan. Driver dapat tetap OFFLINE jika tidak ingin mengaktifkan lokasi operasional latar belakang. Izin overlay/bubble bersifat opsional dan tidak diperlukan untuk fungsi inti order, trip, chat, navigasi atau panggilan.

Kontak

Untuk pertanyaan privasi atau permintaan terkait data, gunakan kanal dukungan resmi yang tersedia melalui situs Transiva di https://transiva.my.id/ atau melalui fitur dukungan resmi di aplikasi.

Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika fitur, hukum, atau cara pemrosesan data berubah. Tanggal pembaruan terbaru ditampilkan di bagian atas halaman.
